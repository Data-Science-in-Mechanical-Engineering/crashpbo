# Preferential Bayesian Optimization with Crash Feedback

This repository contains the implementation of preferential Bayesian optimization (PBO) with crash feedback. 
It includes scripts for running experiments, evaluating results, and demonstrating the PBO process through an interactive Streamlit-based interface.

---

## Setup

To set up the environment, ensure you have the required dependencies installed. You can use a virtual environment or Conda environment for isolation.

1. Clone the repository:
   ``` bash
   git clone <repository-url>
   cd <repository-folder>
   ```

2. Install the requirements
    ``` 
    pip install requirements.txt
    ```

## Reproduce Synthetic Experiments

To reproduce the experiments from the paper, run the following command:
  ```
  bash experiments.sh 
  ```

This script will:

Run experiments for various synthetic functions and configurations.
Evaluate the results and generate plots.
Note: The experiments may take a significant amount of time to complete. The results in the paper were generated by running this on a cluster with parallelization. 

## Evaluation
To evaluate the results of the experiments:

  1. Run the evaluation script:
  ```
  python -m crashpbo.synthetic_experiments.evaluation_synthetic_experiments
  python -m crashpbo.synthetic_experiments.plot_paper
  ```

  2. This will generate:
    - Performance plots.
    - Crash statistics.
    - Rankings of algorithms and modes.
    - LaTeX tables summarizing the results.

## PBO Demo
To run the interactive PBO demo for tuning step response of a PI-controller:

  1. Activate your environment with the installed requirements. 

  2. Start the front-end interface in one terminal:
  ```
  python -m streamlit run crashpbo/interface/pbo_front_end.py
  ```
  3. Start the back-end in another terminal:
  ```
  python -m crashpbo.interface.pbo_back_end step_response
  ```
The front-end will provide a visualization of the optimization process, allowing you to interactively select preferences between parameter sets.

Alternatively you can run a docker: 
  ```
  docker-compose -f docker/docker-compose.step.yml up
  ```

## Example Use Case

An simple synthetic example is provided in the jupyter-notebook. 

One of the applications in the paper is the Quanser Qube-Servo 2.
To run experiments on this platform, plug it in your USB-Port and run the docker command:  
  ```
  docker-compose -f docker/docker-compose.quanser.yml up
  ```
